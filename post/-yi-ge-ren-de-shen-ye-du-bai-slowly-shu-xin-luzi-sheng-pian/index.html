# 一个人的深夜独白——Slowly 书信录·自省篇

2026-08-22 4 分钟阅读 # 书信

一个人的深夜独白——Slowly 书信录·自省篇

这是一个关于"自我"的合集。收录了那些在深夜写信时，不小心说出来的真话——关于孤独、关于选择、关于如何与自己相处。它们不是写给笔友的，而是写给自己的。

一、社交倦怠的诚实面对

【入选理由】 这段文字的动人之处在于它的脆弱感。一个平时犀利、直接的人，在信中承认"我不太擅长说话"、“感觉自己不太适合做研究”——这种反差让整封信变得格外真实。而"有时候我在想我是不是在期待一个能理解我的人"这句话，几乎可以原封不动地放进任何一部文学作品里。

收信人：soukai_na（摩洛哥）

其实，我还挺感谢你的。因为收到你的来信，我才发现原来我写了一封很糟糕的信。这让我意识到，我是一个不太擅长说话的人。不过，我并没有因此而感到沮丧，反而觉得这是一种成长。

我现在在做研究生的课题研究，我感觉我不太适合做研究。因为我的性格比较急躁，总是想要快速的得到结果。但是，研究需要耐心和时间。我觉得，这是一种挑战。不过，我会努力去适应这种挑战。

我觉得，我现在的生活状态，是一种非常有意思的状态。我在这座城市生活了两年多，但是，我并没有完全的融入这座城市。我觉得，这是一种非常有意思的状态。我在这座城市里，就像一个局外人一样，看着这座城市的一切。

有时候我在想，我是不是在期待一个能理解我的人。如果是的话，我想，我应该会很开心。因为，我觉得，能理解我的人，应该是一个非常有趣的人。

二、关于"独特"的代价

【入选理由】 这段文字最打动我的是"我也因为’独特’的追求，错失了许多令他人感到不值的叹息，但我并不感到后悔，因为这是我选择的道路，我要自己负责"。它不回避代价，不美化选择，是一种成熟的自我负责态度。

收信人：Eunyversee（菲律宾）

对于落后的焦虑，你用词很精准，说’焦虑’而不是’痛苦’。‘落后’本身不是痛苦，而是焦虑。比如说，你看到身边的朋友同学都陆续结婚生子，有了家庭，而你还是一个人，这会产生焦虑。比如你看到身边的人事业小有成就，有了家庭，有了车，有了房，而你还在为了维持自己的生存而努力，这也会产生焦虑。

这并不意味着你比他们差，只是你的’时间线’不同而已。

有时候，所谓的落后不一定就是错误或者遗憾，也可以想想，它给你额外带来了些独有的礼物，不是吗？

我也因为’独特’的追求，错失了许多令他人感到不值的叹息，但我并不感到后悔，因为这是我选择的道路，我要自己负责。

三、关于年龄与生日

【入选理由】 这段文字的动人之处在于它的平淡。没有华丽的辞藻，没有深刻的哲理，只有一个人在生日那天的随想。“对我们而言，过好过去、现在、未来每一天，就是我的每天的生日”——这句话用最朴素的方式，表达了对生命最真诚的态度。

收信人：soukai_na（摩洛哥）

你好，soukai_na！

今天是我生日。

我没过生日的习惯。你今天说的那些关于父母的温馨感受，说实话，我没啥体验。

你问我，对生日有什么想法？说实话，我没啥想法。对我们而言，过好过去、现在、未来每一天，就是我的每天的生日，每天的愿望。对于29岁的我而言，好像也和21岁没什么大的区别，也没什么不同，就像平常平淡的19、20岁生日一样。

我是一个不喜欢被别人特别关注的人。我不喜欢被别人特别关注，也不喜欢被别人特别对待。我觉得，每个人都是一样的，每个人都应该被平等对待。

四、关于单身与社会压力

【入选理由】 这段讨论"老年单身生活"的文字，最精彩的是它拆解了问题本身的预设立场。“你的问题里面已经带有了假设”——这是一句非常有力的回应。它不是在回答问题，而是在质疑问题本身的有效性。这种思维能力，在日常对话中非常罕见。

收信人：LaoShi LaoShi

我觉得每个人的选择，是不一样的。就像你现在所担忧的老年生活，假如你认为这是威胁，我想请问你，你怎么知道你的老年，会像你认为的那样？

既然如此，那我认为的威胁是什么？就是我无法在我喜欢的事情上获得’安全感’。这很现实。是的，我没有理由要牺牲现在收益去博取未来的抗风险。

如果说生命是一种权利，那么这种’想要老年’的想象是一种’权利’。只是，我还没有完全理解它。

所以，我没有办法回答这个问题。因为，我没有理由要牺牲现在收益去博取未来的抗风险。你的问题里面已经带有了假设，即：晚年的单身人群是弱势的、孤独的、脆弱的。我想，这不一定正确。我不知道我到底老了，会是什么样？你也不知道。

五、关于友情的筛选标准

【入选理由】 用近乎残酷的坦率定义了自己的社交筛选机制——不是"不合群"，而是"筛选严格"。“能和我只是聊天多年而没有决裂的，大多都是品性较好，三观完整的人”——这句话几乎可以成为一份社交关系的质检标准。

收信人：小澤ちゃん（日本）

关于你说的’为什么很多人用英文写信给我’，我理解你的感受。因为我自己也是这样。我身边的人，大多是用中文交流的。但是，我也有一些朋友，是用英文交流的。我觉得，语言只是一种工具，重要的是内容。

能和我只是聊天多年而没有决裂的，大多都是品性较好，三观完整的人，最起码是脑子各功能健全，缺德的、没脑子的、让我无可克制住厌蠢的，早把我激怒，忍不住攻击或者删除了。

虽然我因为’独特’的追求，错失了许多令他人感到不值的叹息，但我并不感到后悔，因为这是我选择的道路，我要自己负责。

六、关于相亲文化的批判

【入选理由】 用"牲畜配种市场"来形容相亲场景，这种极端的比喻背后是对中国传统婚恋文化最深刻的批判。不是愤怒，不是悲伤，而是一种带着黑色幽默的无奈。

收信人：小澤ちゃん（日本）

我在国内工作的时候一直叫我相亲，各种明示暗示的。有一次逼到情绪崩溃大吵一架，后面就好了。还有过一次交换了联系方式，也可能是相亲认识就很无趣，感觉对方真的就是一个空洞的灵魂。

最近还介绍了在日本工作的一个朋友家小孩，我直接拒绝了，我说我现在没有什么世俗的欲望。（虽然第二天就打脸了，突然遇到了心动男嘉宾，不过已经结束了）相亲这件事情本身就很恶心。之前同事要给别人介绍对象，就把双方条件拿出来说，我一听感觉在牲畜配种市场一样。

我本来也是坚定的想留在这里，生活的蛮安心的。但是在五月初遇到了一个穷凶极恶的昭和老头，我和他在警察局呆了一天，当然我是受害者。这个故事太长了，等回头再讲给你听。导致我现在有一点点PTSD，对于日本老头。

以上就是 Slowly 书信录的全部内容。感谢你读到这里。

这些信件，记录了一个人在两个月内的思考、感受和成长。它们不是完美的，不是深刻的，不是优美的。但它们是真实的。

这就够了。
